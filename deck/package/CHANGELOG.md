# Changelog

格式为 Keep-a-Changelog 子集：有新版时面板第 02 章更新日志自动展示本文件对应版本一节；缺文件或取不到时只给中性提示，安装不受影响。分类用 Added、Fixed、Changed、Security 必显展开，Deprecated、Removed 折叠，Unreleased 与空节忽略。

## [Unreleased]

### Changed

- 更新入口全权委托给更新包：配置页检查更新按钮用包里的入口件默认摆法，更新面板用包的 dialog 原样；本仓不再自带按钮状态机与浮层弹窗。

## [1.7.7] - 2026-10-13

### Fixed

- deck 半边（`deck_*` 工具 / 面板取数 / 预检）在执行世界 PATH 里没有 gh 的机器上整片失败、报「gh 这一次没拿到退出码」：gh 客户端解析出了可执行路径，起进程时却传了裸名。现在按解析出的路径执行；解析结果缺失时如实报环境错误，不再退回裸名。

## [1.7.43] - 2026-10-06

### Added

- 版本管理页新增更新按钮：只取回远端跟踪引用，不合并，不碰工作树；成功后自动重读，身份行领先与落后即为本次更新后的数量。

### Changed
